# Slippi Combo Dumper
A tool for exporting SSBM combos from Slippi replays.  
I use this in combination with Clippi's combo finder to get high quality WebM's of all combos from a folder of slippi replays.  

## Pre-requisites
Ensure ffmpeg is installed on your path, ffmpeg can be downloaded [here](https://www.ffmpeg.org/download.html). Make sure to get a pre-compiled binary from the ```Get packages & executable files``` section.   
To ensure the best dolphin quality, I've included my dolphin playback GFX settings in this repo. The key things to change are the encoding and the bitrate.
